# chris-inspiration-hub

一个用来收集想法、整理资料索引，并练习 Git / GitHub 基本用法的个人仓库。

## 这个仓库做什么

- **资料索引**：把散落各处的资料与链接整理成可检索的清单（Markdown 表格 / CSV）。
- **随手记录**：想法、笔记、速查表、模板，任何值得留痕的文字。
- **练手**：熟悉提交、版本回溯、分支、Pull Request 这套协作流程。

> 仓库是公开的，请勿放入任何涉密、含个人信息或公司内部资料。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `README.md` | 本文件，仓库说明 |
| `LICENSE` | MIT 许可证 |

后续按主题新建子目录（例如 `notes/`、`references/`），不要把所有文件堆在根目录。

## 本地使用

```bash
git clone https://github.com/chrisqiu871-maker/chris-inspiration-hub.git
cd chris-inspiration-hub
```

网页上也能直接操作：点 **Add file** 新建或上传文件，每次改动会留下一条带说明的记录，随时可以回到任意一版。

## 几点约定

- 优先用 Markdown、CSV 这类纯文本，能逐行看到「哪句话被改了」；Word / Excel / PDF 存得住但看不到内部差异，大文件也不适合放这里。
- 提交信息写清楚改了什么，别只写「更新」。
- 文件名避免空格和「最终版 / 最终版2」这类后缀，版本交给 Git 管。
